# Code of Conduct

## Our Standards

This project aims to be useful, respectful, and welcoming for users and contributors.

Examples of expected behavior:

- Be respectful of different experience levels and viewpoints.
- Keep discussions focused on the plugin, bug reports, support, and improvements.
- Provide clear reproduction steps when reporting issues.
- Give constructive feedback when reviewing changes.

Examples of unacceptable behavior:

- Harassment, insults, threats, or personal attacks.
- Dismissive or hostile comments toward users or contributors.
- Publishing private information without permission.
- Spam or unrelated promotion.

## Reporting

If you see behavior that violates this code of conduct, please report it through GitHub Issues or contact the maintainer directly.

Reports should include enough context to understand what happened. The maintainer may remove comments, close discussions, block users, or take other reasonable moderation actions.

## Scope

This code of conduct applies to this repository, its issue tracker, pull requests, discussions, and other project spaces.
